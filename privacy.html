アクセスするデータと目的

本人が許可した OAuth スコープに基づき、アカウント識別情報、メール、ファイル、文書、表計算、プレゼンテーション、予定、タスクにアクセスします。これらは本人が依頼する検索、要約、整理、文書作成、予定管理などの機能を提供するために使用します。

処理と外部サービス

アプリは所有者が管理する環境で動作します。指示の実行に必要な Google データの一部が、Hermes で選択した外部 AI プロバイダーにプロンプトやツール結果として送信される場合があります。送信先と処理条件は使用中のプロバイダーおよび設定に依存します。利用者は機密性を考慮して連携とモデルを選択してください。

所有者は、本連携で取得した Google データを販売、広告ターゲティング、信用審査、汎用 AI モデルの学習用データ作成のために使用しません。第三者への送信は本人の依頼する機能の提供に必要な範囲に限定します。

保存・保護・削除

OAuth 認証情報は所有者の実行環境に保存されます。Google データの一部は会話履歴、ツール出力、ログ、生成ファイル、バックアップに残る場合があります。全データ共通の自動削除期限は設けていません。所有者が各保存先の履歴・ファイル・バックアップを管理し、不要になったデータを削除します。外部サービス上の処理・保存は各サービスの契約と設定にも従います。

Google アカウントの第三者接続設定でアクセスを取り消すと、以後のアクセスを停止できます。取り消しだけでは既存の履歴や生成物は削除されないため、別途保存先から削除してください。認証情報や個人データを公開リポジトリに保存しない運用とします。

Google API Services User Data Policy

Hermes FRIDAY Local’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

この説明サイトと連絡先

本サイトは GitHub Pages 上の静的な説明サイトです。アプリ独自のアクセス解析や Google ログイン機能はありません。ホスティング事業者は運用上のアクセス情報を処理する場合があります。連絡は下記リポジトリの Issue を利用してください。公開 Issue に個人データ、メール本文、認証情報を記載しないでください。
